Tokens & theming

Theme-aware

Every component on this page reads tokens only — no hardcoded values. Flip the theme switch (top right) and the entire system reskins. Tokens marked 🔒 fixed are platform-level and do not change across partners.

Under the hood the system is a three-tier architecture — [arta] · [ref | sys | cmp] · [role]: a ref layer of raw ladders (10–90 color steps, 4px grid), a sys layer of semantic intent that only aliases ref, and a cmp layer of per-component contracts where hardcoded values fail the build. A partner theme like Meridian is a sys-override file — zero component code. One example chain: #a8cdf0 → ref.color.sky.40 → sys.action.primary → cmp.btn.primary.bg. The full token set runs live in the Storybook, and the same generated CSS powers the interactive prototype via a sync pipeline.

Typography & the legal style

Legal style — proposed

Two brand faces, verified from artafinance.com's CSS: Rotunda (self-hosted webfont, weights thin→black) is the UI, body and product-display face — the rounded geometric sans across app and site. Ofelia Display 500 (Adobe Typekit) is the marketing headline face, set with positive tracking at 130% leading — reserved for brand moments, never product screens. Both are licensed; this page renders geometric fallbacks while the tokens carry the real stacks. What lending adds: a legal type style — generous line-height, no letterspacing, footnote support — because disclosure text must be genuinely readable, not just present.

Core vs configurable

The white-label line

The theme switch above is the demo: Meridian (a fictional online brokerage) changes tokens — color, radius, gradients, CTA treatment. It cannot touch the trust layer. That line is what makes this a platform rather than a reskin service.

🔒 Platform-fixed

  • Disclosure content & placement — Key Terms always visible
  • Consent mechanics — separate, never pre-checked
  • Semantic colors — error, positive
  • Flow skeleton — confirm → income → terms → review → decision
  • Decisioning, security, accessibility floor

✦ Partner-configurable

  • Design tokens — palette, radius, type
  • Brand moments — gradients, card art, logo
  • CTA treatment — within contrast rules
  • Copy tone — within compliance guardrails
  • Entry points & reward currency
Arta's own brand is simply theme #1 in the same pipeline.
